# Task Dashboard (Todo App)

A simple web-based task management dashboard. Add, organize, and track your daily tasks with priorities, due dates, filters, sorting, and persistent storage in your browser.

## Features
- Add tasks with title, description, due date, and priority (Low, Medium, High)
- Mark tasks as complete/incomplete
- Edit and delete tasks
- Filter by All, Pending, Completed, or High Priority
- Sort by Due Date, Priority, or Creation Date
- Dashboard stats (Total, Pending, Completed, High Priority)
- Completion progress bar
- Tasks saved in localStorage (persist across page reloads)
- Responsive, clean UI

## Getting Started
1. Open index.html in your web browser.
2. Add your first task using the "Add New Task" form.
3. Your tasks will be saved automatically in localStorage.

## Files
- index.html - UI structure
- style.css - Styling
- script.js - App logic and localStorage handling
